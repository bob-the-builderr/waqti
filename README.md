# وقتي — توصيل كل حاجة في الفيوم

منصة توصيل زي طلبات للفيوم: مطاعم وبقالة وصيدليات وخضار ولحوم ومخابز، مندوب واحد لحد 3 محلات في المشوار.

## التطبيقات (Expo SDK 58 + Supabase)

| الفولدر | التطبيق | بورت الويب |
| --- | --- | --- |
| `apps/customer` | تطبيق العميل «وقتي» | 8081 |
| `apps/merchant` | تطبيق المحلات «وقتي للمحلات» | 8082 |
| `apps/driver` | تطبيق المناديب «وقتي للمناديب» | 8083 |
| `apps/admin` | لوحة الإدارة (ويب) | 8084 |

## التشغيل

في كل تطبيق:

```bash
cd apps/customer
cp .env.example .env
npm install
npx expo start --web --port 8081
```

- الاختبار على الويب أو بنسخة APK (`npx eas-cli@latest build -p android --profile preview`)، مش Expo Go.
- `.env` فيه رابط Supabase والمفتاح العام (publishable) بس. المفتاح السري عمره ما يتحط في الكود.

## قاعدة البيانات

ملفات `supabase/001…018` بتتلصق بالترتيب في Supabase SQL Editor. كل ملف مكتوب في أوله بيعمل إيه، وتشغيله مرتين مش بيبوّظ حاجة.

## مراجع

- `brief/`: خطة المشروع ونتايج المراجعات.
- `brand/`: الهوية (الاسم، اللوجو، الألوان).
